1. toggle-overlength.nvim      *toggle-overlength.nvim-toggle-overlength.nvim*

A Neovim plugin to toggle the highlighting of text exceeding the column length.


==============================================================================
2. Installation                          *toggle-overlength.nvim-installation*

Install the plugin with your package manager:

lazy.nvim <https://github.com/folke/lazy.nvim>:

Here default configuration with a column length of `120`.

>lua
    {
        "fouladi/toggle-overlength.nvim",
        config = function()
            require("toggle-overlength").setup({})
        end,
    }
<

Use other column lengths, colours, or a custom keymap if you prefer:

>lua
    {
        "fouladi/toggle-overlength.nvim",
        config = function()
            require("toggle-overlength").setup({
                column_length = 80,      -- Set column length to 80
                ctermbg = "red",         -- Set terminal background color to red
                guibg = "#ff0000",       -- Set GUI background color to red
                keymap = "<leader>th",   -- Optional: set a toggle keymap
            })
        end,
    }
<


==============================================================================
3. Usage                                        *toggle-overlength.nvim-usage*

After setup, the following command will be available. The command works in
toggle mode: the same command turns highlighting on and off.


COMMANDS: ~

`:ToggleHiOverLength` — toggle the overlength highlighting.


KEY MAPPINGS: ~

No keymap is set by default. Pass `keymap` in the setup options to bind one:

>lua
    require("toggle-overlength").setup({ keymap = "<leader>th" })
<
